🚀 Cómo Iniciar el Proyecto

1. Backend (API Server)

# Navegar a la carpeta del backend
cd barberia-api

# Instalar dependencias (si no lo hiciste)
npm install

# Iniciar servidor
npm run dev # Modo desarrollo (nodemon)
# O
npm start # Modo producción

# Servidor corriendo en: http://localhost:3000

2. Frontend (Aplicación Web)

# Opción A: Abrir HTML directamente
firefox frontend/index.html

# Opción B: Con Live Server (VS Code)
Click derecho en index.html → Open with Live Server

# Opción C: Servidor Python
cd frontend
python -m http.server 8000
# Ir a http://localhost:8000
📌 Importante: Asegúrate de que:
  • El servidor backend está corriendo en puerto 3000
  • MySQL está conectado y la BD existe
  • El archivo .env tiene las credenciales correctas
  • Abres el frontend en un navegador compatible (Chrome, Firefox, Edge)

🧪 Flujo de Prueba Completo

  1. Ir a inicio: http://localhost:8000 (o similar)
  2. Registrarse: Click en "Registrarse", completar formulario
  3. Login: Iniciar sesión con credenciales creadas
  4. Ver barberos: Click en "Barberos"
  5. Reservar: Click en "Reservar Cita"
  6. Completar pasos:
    1. Seleccionar barbero
    2. Seleccionar tipo de corte
    3. Seleccionar fecha y hora
    4. Confirmar reserva
  7. Éxito: Redirección a panel de usuario

🐛 Solución de Problemas

Problema: "Cannot GET /api/..."

→ El servidor backend no está corriendo. Ejecuta: cd barberia-api && npm run dev

Problema: "Access denied for user 'root'"

→ La contraseña en .env es incorrecta. Verifica en MySQL Workbench y actualiza .env

Problema: CORS error

→ Ya está configurado en el servidor. Si persiste, verifica que estés usando http://localhost:3000

Problema: No carga CSS/JS

→ Asegúrate de abrir desde un servidor (http://), no directamente (file://)

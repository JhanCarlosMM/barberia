📖 Guía Rápida

  1. Test Servidor: Verifica que el backend está corriendo en puerto 3000
  2. Obtener Barberos: Prueba si la BD tiene registros en la tabla barberos
  3. Obtener Cortes: Prueba si la BD tiene tipos de corte registrados
  4. Test Disponibilidad: Prueba el endpoint más crítico para reservas

🐛 Solución de Problemas

Si todos los tests fallan:

  1. Verifica que Node.js está corriendo: cd barberia-api && npm run dev
  2. Verifica que MySQL está corriendo y conectado
  3. Comprueba el archivo .env tiene las credenciales correctas
  4. Abre la consola del navegador (F12) y busca errores CORS
  5. Reinicia el servidor backend

📞 Contacto

Si los tests siguen fallando, revisa los logs del servidor en la terminal donde ejecutaste npm run dev
